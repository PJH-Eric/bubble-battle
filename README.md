# 泡泡大作戰 💧🐱

可愛動物園的水球對戰。丟水球把對手噴成**泡泡**，泡泡裡的人再被炸一次才真的出局；
被困住時**左右方向交替按**可以加快掙脫。一局 3 分鐘，最後 45 秒**水位開始上升**，
最外圈一圈一圈變成硬塊，逼大家到中間決勝負。

> 目前進度：**單機與線上都做好了** —— 四段電腦難度、全部道具、線上大廳與房間、組隊、
> 觀戰、邀請連結、聊天室、斷線重連都能用。詳見 [規劃書.md](規劃書.md)。
>
> **零依賴**：不用 `npm install`，雙擊 `啟動遊戲.bat` 就能玩（連 WebSocket 伺服器都是自己寫的）。

## 最快開始

雙擊 **`啟動遊戲.bat`**（第一次會自動 `npm install`），瀏覽器會打開 <http://localhost:3050>。
視窗裡也會印出同網段網址，同一個 Wi-Fi 的平板、手機輸入那個網址就能玩。

指令版：

```bash
npm install
npm start        # http://localhost:3050
```

## 玩法

| | |
|---|---|
| 移動 | 方向鍵／WASD；平板手機用左下搖桿（設定可改成全螢幕滑動） |
| 放水球 | 空白鍵；平板手機按右下大鈕 |
| 水球 | 放下去 **3 秒**後爆炸，水柱往四方噴，長度＝威力。硬塊擋得住、軟箱會被炸掉、碰到別顆水球會**連鎖引爆** |
| 預告 | **沒有範圍預告**，水球越跳越快就是要爆了 |
| 中招 | 變成**水球泡泡**完全不能動，**泡泡一破就出局**（個人混戰撐 3.5 秒、組隊 5 秒） |
| 活下來 | 只有兩條路：**隊友走到你身上救你**，或身上有**針**時按放水球鍵自己戳破（用一次就沒了） |
| 補刀 | 泡泡狀態再被水柱掃到，也是直接出局 |
| 勝負 | 最後一個沒出局的人獲勝；時間到就比存活人數、再比破箱數。**對局中地圖不會自己改變** |

### 道具

**圓底＝好道具**（水球+1、威力+1、溜冰鞋、**手套**、針、護盾糖）
**三角底＝壞道具**（烏龜變慢、迷你水球威力剩 1、亂步鞋方向相反）

形狀本身就分得出好壞，不必只靠顏色。被淘汰的人會**噴出一半道具**給大家撿。
拿到**手套**之後撞向水球就會把它踢出去，一路滑到撞牆、撞人或撞到另一顆水球才停。

### 電腦對手

四段難度，行為真的不一樣：

| 難度 | 個性 |
|---|---|
| 幼幼班 | 只撿道具炸箱子，看到人會退開，**不補刀**，讓小朋友幾乎一定贏 |
| 簡單 | 會搶道具，反應慢 0.6 秒，常常把自己堵死 |
| 普通 | 會算逃生路線、會堵走廊、會補刀 |
| 困難 | 反應 0.12 秒、會算連鎖、會封死轉角、專挑泡泡補刀 |

單機可以放 **1～7 個電腦對手，每一個單獨選難度**（一個幼幼班陪玩、一個困難來練都行）。

## 線上對戰

首頁按「跟別人玩」就會進大廳。

- **快速加入**：一鍵丟進人最多且還沒開始的房；沒有房就自動幫你開一間等人
- **房間**：房主可以改模式（個人／組隊）、人數上限（2–8，預設 4）、地圖、場景、負面道具，
  也可以加減**電腦對手**、**踢人**；房主離開會自動把房主交給下一個人
- **準備**：全員按「準備好了」房主才能開始，開場有 3 秒倒數
- **觀戰**：席位滿了或對局已經開始就自動轉觀戰（會明白告訴你），觀戰者可以聊天、看得到全場資訊，
  這一局結束後就能入座
- **邀請連結**：房主產生的連結不設時限，房間還在就一直有效，可以複製也可以撤銷重發
- **聊天室**：固定在左下角，有快捷短語（好啊！／救我！／小心！…），不會打字也能溝通
- **斷線**：30 秒內回來可以接回原本的席位，超過就判定離場

連線是自己寫的 WebSocket（`lib/ws.js`），伺服器 30Hz 跑規則、15Hz 送快照，
前端做本地預測、對帳與 120 毫秒插值，所以按下去馬上就會動。

## 專案結構

```
public/js/rules.js      ★ 規則核心（純函式，之後線上模式由伺服器跑同一支）
public/js/ai.js           四段電腦對手，產生和真人一樣格式的輸入
public/js/maps.js        10 張固定地圖 + 隨機生成
public/js/rng.js          可注入種子的亂數（重播、測試、同步都靠它）
public/js/render.js       手繪向量 SVG 繪圖
public/js/input.js        鍵盤／虛擬搖桿／全螢幕滑動
public/js/audio.js        泡泡水聲音效（WebAudio 合成）
public/js/online.js       連線與自動重連
public/js/net.js          本地預測、對帳、插值
public/js/config.js       全站唯一的 server URL 入口
lib/ws.js                 自己寫的 WebSocket 伺服器（所以整包零依賴）
lib/rooms.js              房間、席位、觀戰、準備、邀請、聊天
public/js/themes/         角色與場景外觀，純資料，加一套＝加一個檔
tests/verify.js           規則核心單元測試
scripts/match-check.js    讓電腦互打，確認整局跑得完、四段難度有差
```

## 測試

```bash
npm test            # 規則核心單元測試（61 項）
npm run test:match  # 電腦互打，檢查整局跑得完與四段難度差異
npm run test:online # 房間邏輯與真的連上伺服器跑一輪
npm run verify      # 三個一起跑
```

## 部署

- 伺服器：Render 免費方案（`render.yaml`），健康檢查 `/health`，大廳人數 `/api/presence`
- 前端：GitHub Pages（`.github/workflows/pages.yml`），建置時用 repo 變數 `GAME_SERVER_URL`
  注入到 `public/js/config.js`，程式碼裡不寫死任何網址
- 正式環境記得把 Render 的 `ALLOW_ORIGIN` 設成前端網址
